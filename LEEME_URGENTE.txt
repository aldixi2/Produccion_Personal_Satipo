Esta versión conserva el diseño con barra lateral azul, cuatro tarjetas KPI, gráfico diario y matriz de producción.
Se corrigió un error JavaScript: el cargador del manifiesto intentaba usar la variable inexistente `m` después de cargar el archivo, por lo que nunca llegaba a cargar los registros.

PUBLICACIÓN EN GITHUB PAGES
1. Descomprime este ZIP.
2. Sube el CONTENIDO de esta carpeta a la raíz del repositorio (index.html y carpeta data al mismo nivel).
3. Confirma que exista data/manifest.json y los archivos data/base_AAAA_MM.json.
4. En GitHub Pages, publica desde la rama/carpeta donde está index.html.
5. Después de publicar, recarga con Ctrl+F5.

No requiere XAMPP ni ejecutar archivos .bat. GitHub Pages es estático; cualquier función PHP no se ejecuta allí.
