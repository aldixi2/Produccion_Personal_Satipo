  index.html
  data/
    manifest.json

IMPORTANTE:
1. Sube TODO el contenido de esta carpeta al repositorio.
2. index.html debe quedar en la raíz de la carpeta publicada por GitHub Pages.
3. La carpeta data debe quedar al mismo nivel que index.html.
4. No necesitas XAMPP, PHP ni el archivo .bat para GitHub Pages.
5. El dashboard carga primero data/manifest.json y usa rutas relativas compatibles con repositorios tipo:
   https://usuario.github.io/repositorio/
6. Si un archivo no carga, abajo del dashboard aparecerá "Error de datos" con la URL y el código HTTP.
7. Los datos no se eliminan ni se inventan: se mantienen los JSON del proyecto.
8. El diseño corresponde a la versión compacta anterior 2, con menos scroll y vistas de resumen/análisis/histórico.
