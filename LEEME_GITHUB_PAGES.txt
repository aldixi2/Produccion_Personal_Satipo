VERSIÓN GITHUB PAGES

1. Sube TODA esta carpeta a tu repositorio.
2. El archivo principal es index.html.
3. Conserva la carpeta data/ completa.
4. No cambies los nombres de los archivos JSON.
5. GitHub Pages debe publicar desde la rama/carpeta donde está index.html.
6. No necesitas XAMPP, PHP ni INICIAR_DASHBOARD.bat para GitHub Pages.

La carga de datos usa rutas relativas al index.html y cache no-store.
El dashboard carga inicialmente SET 26 cuando está disponible.

Si aparece "Error de datos" en la barra de estado, ese mensaje indica exactamente
qué archivo o ruta no pudo cargar.
